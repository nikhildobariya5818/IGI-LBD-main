# LBD Diamonds Report Generator - User Guide

## Quick Start

### Step 1: Navigate to LBD Diamonds Report
1. Open the Report Processor application
2. Click the **"LBD Diamonds Report"** tab at the top of the page
   - You'll see three tabs: Standard Reports, Mini Reports, and LBD Diamonds Report

### Step 2: Enter Client Information
1. **Client Name:** Type the client's name in the text field
   - This name will appear prominently in the generated report
   - Example: "John Smith" or "ABC Jewels Ltd"

### Step 3: Upload Your Diamond Report PDF
1. Click the **"Click to upload PDF"** area or drag & drop a PDF file
2. Select your IGI diamond report PDF file from your computer
   - **Accepted formats:** PDF files only
   - **Maximum file size:** Check with your administrator (typically 100 MB)
3. You'll see confirmation: "✓ [filename.pdf]"

### Step 4: Generate the Report
1. Click the **"Generate IGI Report"** button
   - The button will only activate when both fields are filled
2. Watch the progress indicator:
   - **0-20%:** Uploading your PDF
   - **20-80%:** Processing and extracting data
   - **80-100%:** Generating your report PDF

### Step 5: Download Your Report
Your report will automatically download as:
- **Filename format:** `IGI_Report_[ClientName]_[Date].pdf`
- **Example:** `IGI_Report_John_Smith_10-07-2026.pdf`

## Troubleshooting

### Issue: "Invalid file type. Please upload a PDF file."
**Solution:** Make sure you're uploading a PDF file, not another format like .jpg or .png

### Issue: "Please enter a client name"
**Solution:** Fill in the Client Name field before clicking Generate

### Issue: "Please upload a PDF file"
**Solution:** Make sure you've selected and uploaded a PDF file

### Issue: "Back-end not connected" or API error
**Solution:** 
- Check that the backend server is running
- Wait a moment and try again
- Contact your system administrator if the problem persists

### Issue: "Processing failed"
**Solution:**
- Make sure your PDF is a valid IGI diamond report
- Try uploading a different report to verify
- Check file size doesn't exceed limits
- Ensure your internet connection is stable

## Tips & Best Practices

1. **Client Names:** Keep client names simple and professional
   - ✅ "John Smith"
   - ✅ "ABC Jewels Ltd"
   - ❌ "Client@#$%^&*()"  (special characters may cause issues)

2. **PDF Quality:** Ensure your source PDF is:
   - A valid IGI diamond report
   - Not password-protected
   - Not corrupted or damaged
   - Clear and readable

3. **Processing Time:** 
   - Normal processing takes 2-5 seconds
   - Larger PDFs might take longer
   - Keep the page open during processing

4. **Multiple Reports:** You can generate multiple reports in sequence
   - Just clear the form and upload a new PDF
   - Each report downloads separately

## Frequently Asked Questions

### Q: Can I modify the generated report?
**A:** The generated PDF is a final document. For modifications, regenerate with different input or contact support for custom formatting.

### Q: What happens if my internet disconnects during upload?
**A:** The upload will fail, and you'll see an error. You can retry by reloading the page and uploading again.

### Q: Can I batch process multiple reports?
**A:** Currently, you must generate reports one at a time. For bulk processing, contact your administrator.

### Q: How long are uploaded files kept?
**A:** Files are automatically deleted after processing. No files are permanently stored.

### Q: Can I change the report format or size?
**A:** The LBD Diamonds Report uses a fixed 14 × 8.5 inch format for standardization. Contact your administrator for custom formats.

### Q: What if my PDF doesn't have all the diamond information?
**A:** The system will extract available information. Missing fields will show as "N/A" in the report.

## Getting Help

If you encounter issues:

1. **Check the error message** - It usually explains what went wrong
2. **Try again** - Sometimes temporary issues resolve on retry
3. **Use a different PDF** - Test with another report to isolate the problem
4. **Contact Support** - Reach out to your system administrator with:
   - Error message (copy/paste exactly)
   - Screenshot of the problem
   - PDF file details (filename, size)
